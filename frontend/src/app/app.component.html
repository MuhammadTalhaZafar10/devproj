Reproduction: paper against ours

Task: classify a building's performance class (Low, Medium, High, as terciles of kWh per m² per year). Setup follows the paper: a random 20% test split and 5-fold cross-validation on the rest, repeated over five different splits. Random Forest and Gradient Boosting come from the paper. LightGBM and XGBoost do not.

What to keep in mind

  • The paper does not publish its Low, Medium and High cutoffs, and its code repository is empty. We used terciles of kWh per m² per year: below {{ r.cohort.class_cutoffs_kwh_m2_yr[0] | number: '1.0-0' }} is Low, above {{ r.cohort.class_cutoffs_kwh_m2_yr[1] | number: '1.0-0' }} is High.
  • The paper builds 374 features with several R and Python packages. We built {{ r.dataset_100k.feature_columns }} simpler ones from the hourly profile, and none can encode absolute consumption.
  • Our cohort is {{ r.cohort.buildings | number }} buildings across {{ r.cohort.sites }} sites. The paper used {{ r.paper.buildings | number }}. Numbers are comparable in size, not identical.
  • Gradient Boosting uses scikit-learn defaults because the paper does not list its tuned values.
